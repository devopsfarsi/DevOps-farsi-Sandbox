# DevOps Farsi Sandbox — Product Overview

## DevOps Farsi Sandbox چیست؟

DevOps Farsi Sandbox یک پلتفرم تمرینی و آزمایشگاهی برای یادگیری عملی DevOps است.

هدف این پروژه ایجاد محیط‌هایی واقعی، ایزوله و موقت برای مهندس‌های DevOps است تا بتوانند سناریوهای نزدیک به محیط Production را تمرین کنند.

در این پلتفرم کاربر بدون نیاز به آماده‌سازی زیرساخت شخصی، فقط با ورود به سایت می‌تواند یک Sandbox دریافت کند و روی آن تمرین انجام دهد.

---

## ایده اصلی پروژه

در دنیای واقعی DevOps فقط یادگیری دستورات کافی نیست.

یک مهندس DevOps باید بتواند:

- سرویس‌ها را Deploy کند
- مشکلات سیستم را Debug کند
- Metrics و Logs را بررسی کند
- Incidentها را مدیریت کند
- علت اصلی مشکل را پیدا کند

DevOps Farsi Sandbox این شرایط را در یک محیط کنترل‌شده شبیه‌سازی می‌کند.

---

## جریان کلی کاربر

کاربر:

1. وارد سایت می‌شود.
2. یک Template آموزشی انتخاب می‌کند.
3. سیستم برای او یک Sandbox اختصاصی ایجاد می‌کند.
4. کاربر وارد Workspace خودش می‌شود.
5. از IDE، Terminal و Monitoring استفاده می‌کند.
6. Task را انجام می‌دهد.
7. سیستم نتیجه را Validation می‌کند.
8. Score کاربر ثبت می‌شود.
9. Sandbox حذف می‌شود.

---

## مخاطب هدف

DevOps Farsi Sandbox برای این سطوح طراحی شده است:

- **مبتدی** — آشنایی اولیه با لینوکس و Docker دارد؛ می‌خواهد اولین تجربه‌های واقعی را کسب کند.
- **جونیور** — مفاهیم پایه را می‌شناسد؛ به محیط واقعی برای تمرین Debug و Incident نیاز دارد.
- **میان‌رده** — می‌خواهد سناریوهای پیچیده‌تر (Multi-Service، Monitoring، Incident Response) را تمرین کند.

هر Template سطح دشواری مشخصی دارد و کاربر بر اساس سطح خودش انتخاب می‌کند.

---

## چرا این پروژه لازم است؟

یادگیری DevOps معمولاً دو مشکل اصلی دارد:

1. **نبود محیط تمرینی واقعی** — بیشتر آموزش‌ها فقط توضیح می‌دهند (Kubernetes چیست؟ Docker چیست؟) اما کاربر تجربه حل مشکل واقعی ندارد.
2. **سختی ساخت محیط تمرین** — برای تمرین واقعی باید Kubernetes Cluster، Monitoring Stack، Application و Network راه بیفتد؛ این کار برای تازه‌کارها سخت و زمان‌بر است.

DevOps Farsi Sandbox هر دو مشکل را حل می‌کند: محیط از قبل آماده است و کاربر فقط روی حل مسئله تمرکز می‌کند.

---

## ارزش برای کانتربیوترها

این پروژه فقط برای یادگیرندگان ارزش ندارد؛ برای کانتربیوترها هم:

- تجربه طراحی و ساخت یک سیستم واقعی
- تمرین Git، Code Review و همکاری در پروژه Open Source
- رزومه‌ای که نشان می‌دهد «زیرساخت واقعی» ساخته‌اید

---

## خارج از Scope (فعلاً)

- جایگزینی دوره‌های آموزشی — Sandbox محیط تمرین است، نه دوره.
- اجرای کد دلخواه کاربران با دسترسی آزاد — امنیت اولویت است.
- چند کاربر روی یک Sandbox — هر Sandbox فقط برای یک کاربر است.
