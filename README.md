# DevOps Farsi Sandbox

**DevOps Farsi Sandbox** قراره یه پروژه کاملاً Open Source باشه که خود بچه‌های کامیونیتی **DevOps فارسی** با هم بسازنش، توسعه‌ش بدن و کم‌کم بزرگ‌ترش کنن.

ولی چیزی که می‌خوایم بسازیم فقط یه زیرساخت یا یه پلتفرم فنی نیست.

هدف اصلی ما اینه که کنار هم یه **فرهنگ یادگیری و اشتراک تجربه** بسازیم.

فرهنگی بر پایه‌ی:

**Continuous Learning**
**Continuous Sharing**

یعنی قرار نیست یادگیری‌مون با تموم شدن یه دوره یا دیدن چندتا ویدیو تموم بشه.

می‌خوایم با **ساختن، تجربه کردن، خراب کردن، حل کردن و به اشتراک گذاشتن تجربه‌هامون**، همیشه در حال یاد گرفتن از همدیگه باشیم.

---

## Sandbox قراره چی باشه؟

DevOps Farsi Sandbox قراره یه **محیط واقعی و مشترک برای یادگیری و تجربه DevOps** باشه.

اینجا قراره کارها رو به شکل Task و Challengeهای کوچیک تعریف کنیم؛ ولی هر Task صرفاً برای این نیست که یه چیزی بسازیم و تیکش رو بزنیم.

هر Task باید یه **هدف مشخص** داشته باشه و در نهایت به یه نتیجه خوب و قابل استفاده یا یه تجربه ارزشمند برای پروژه و اعضای کامیونیتی برسه.

در طول این مسیر قراره:

* از همدیگه یاد بگیریم
* تجربه‌هامون رو با هم به اشتراک بذاریم
* با مشکلات واقعی روبه‌رو بشیم
* راه‌حل‌های مختلف رو امتحان کنیم
* Code و Infrastructure همدیگه رو Review کنیم
* و مهم‌تر از همه، با ساختن خود Sandbox یاد بگیریم که یه محیط واقعی رو چطوری طراحی، پیاده‌سازی و نگهداری کنیم.

---

## خود Sandbox رو هم با هم می‌سازیم

یکی از قسمت‌های جذاب پروژه اینه که قرار نیست یه Sandbox آماده داشته باشیم و فقط بیایم ازش استفاده کنیم.

**خودمون قراره بسازیمش.**

در قدم‌های اول، Contributors پروژه روی ساخت زیرساخت موردنیاز برای این پلتفرم کار می‌کنن.

از Infrastructure و Network گرفته تا Deployment، CI/CD، Monitoring، Security و هر چیز دیگه‌ای که برای ساخت یه محیط واقعی لازم داشته باشیم.

این یعنی کسی که توی ساخت Sandbox مشارکت می‌کنه، فقط یه ابزار خاص یاد نمی‌گیره؛ بلکه تجربه‌ی کار روی یه **پروژه واقعی و تیمی** رو هم به دست میاره.

---

## 🚀 بعدش قراره چه اتفاقی بیفته؟

هدف نهایی اینه که Sandbox تبدیل بشه به یه محیط عملی که **Juniorها و Mid-levelها** بتونن توش تجربه کسب کنن و خودشون رو محک بزنن.

مثلاً فرض کن یه Junior Developer هستی و می‌خوای یه پروژه کوچیک بسازی.

میای داخل Sandbox، پروژه‌ات رو ایجاد می‌کنی و کم‌کم می‌ری سراغ:

```text
Build
  ↓
Test
  ↓
Deploy
  ↓
Monitor
```

پروژه‌ات رو واقعاً Deploy می‌کنی و با چالش‌هایی که توی یه محیط واقعی وجود داره روبه‌رو می‌شی.

ولی داستان اینجا تموم نمی‌شه.

وقتی پروژه‌ات با موفقیت Deploy شد، می‌تونیم روی همون پروژه یه **Incident** ایجاد کنیم.

حالا باید بشینی بررسی کنی که چی شده:

```text
Incident
   ↓
Investigate
   ↓
Find the Root Cause
   ↓
Fix
   ↓
Verify
   ↓
Document & Share
```

یعنی باید مشکل رو پیدا کنی، Root Cause رو بفهمی، حلش کنی، مطمئن بشی همه‌چیز دوباره درست کار می‌کنه و در نهایت تجربه‌ای که به دست آوردی رو با بقیه به اشتراک بذاری.

اینجوری دیگه فقط یه Lab انجام ندادی؛ یه تجربه نزدیک‌تر به **دنیای واقعی** داشتی.

---

## اصلاً چرا داریم این کار رو می‌کنیم؟

خیلی‌هامون وقتی وارد مسیر DevOps یا حتی Software Engineering می‌شیم، با یه مشکل مشترک روبه‌رو هستیم:

**تجربه واقعی پروژه‌ای نداریم.**

ممکنه Docker، Kubernetes، CI/CD یا کلی ابزار دیگه رو یاد گرفته باشیم، ولی چقدر فرصت داشتیم روی یه پروژه واقعی کار کنیم؟

چقدر فرصت داشتیم:

* با بقیه تیم کار کنیم؟
* Code Review بگیریم؟
* Infrastructure بسازیم؟
* چیزی رو Deploy کنیم؟
* با یه مشکل واقعی روبه‌رو بشیم؟
* Debug کنیم؟
* Incident داشته باشیم؟
* و بعد تجربه‌مون رو با بقیه به اشتراک بذاریم؟

Sandbox قراره کمک کنه این فاصله کمتر بشه.

اینجا می‌تونیم چیزی بسازیم، Deployش کنیم، خرابش کنیم، مشکلش رو پیدا کنیم، درستش کنیم و از چیزی که یاد گرفتیم برای نفر بعدی استفاده کنیم.

پس هر Task قرار نیست فقط یه Task باشه.

می‌تونه تبدیل بشه به یه **تجربه واقعی**.

---

## این پروژه برای همه‌ست

DevOps Farsi Sandbox قرار نیست پروژه‌ی یه نفر یا یه تیم خاص باشه.

**قرارِ خود جامعه فارسی‌زبان DevOps فارسی بسازتش.**

هر کسی می‌تونه یه بخشی از پروژه رو جلو ببره، چیزی یاد بگیره، چیزی یاد بده، تجربه‌ش رو به اشتراک بذاره و در ساخت این محیط سهیم باشه.

حتی خود Sandbox هم قراره در طول زمان با مشارکت اعضای کامیونیتی تغییر کنه و بهتر بشه.

هدف ما فقط ساختن یه Sandbox نیست.

می‌خوایم یه جایی داشته باشیم که بتونیم توش:

**یاد بگیریم → بسازیم → خراب کنیم → درست کنیم → به اشتراک بذاریم → رشد کنیم**

و دوباره همین چرخه رو تکرار کنیم.

**Learn → Build → Break → Fix → Share → Grow 🚀**

اگر حس می‌کنی تجربه کار روی پروژه‌های واقعی توی رزومه‌ات کمه، یا دوست داری توی ساخت یه پروژه Open Source واقعی کنار بقیه مشارکت کنی، **DevOps Farsi Sandbox می‌تونه جای خوبی برای شروع باشه.**
